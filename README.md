# Land Sliders 3D

Ein 3D-Klon von *Land Sliders* (Prettygreat) mit [Three.js](https://threejs.org/).

## Spielprinzip

Wie im Original bewegst du nicht die Figur, sondern **das Land selbst**:
Wische mit Maus oder Finger über den Bildschirm, um die Insel zu kippen —
die kleine Spielfigur rutscht dann den Hang hinunter.

- ⭐ Sammle alle Sterne ein, um ins nächste Level zu kommen
- 🪨 Felsen und Bäume blockieren den Weg (Abprallen!)
- 🌊 Fall nicht von der Inselkante, sonst verlierst du ein Leben
- ❤️ 3 Leben, 5 Level — pro Level mehr Sterne und mehr Felsen

## Starten

Einfach `index.html` in einem Browser öffnen (Three.js wird per CDN geladen),
oder lokal einen kleinen Server starten:

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

Funktioniert mit Maus und Touch.
